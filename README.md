# Doğukan Akın — Backend Engineer

A dependency-free static portfolio for [dogukanakin.github.io](https://dogukanakin.github.io), focused on backend engineering with Node.js and TypeScript.

## Local development

Serve the repository root with any static file server. For example:

```bash
python3 -m http.server 8080
```

Then open <http://localhost:8080>. No package installation, build step, paid service, custom domain, or API key is required.

## GitHub Pages

The site is published from the `main` branch and the repository root using GitHub Pages' **Deploy from a branch** source. The public site is available at <https://dogukanakin.github.io>.

## Files

- `index.html` — semantic page structure and portfolio content
- `styles.css` — responsive dark visual system
- `script.js` — mobile navigation and current-year footer
